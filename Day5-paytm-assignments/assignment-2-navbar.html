Learned That width and height property have only 5 default values like w-25, w-50, w-75, w-100, w-auto

For padding,margin we have 7 default values like p-0(total zero pixcels),p-1,p-2,p-3,p-4,p-5 and p-auto same goes for margin(m) and for top(pt,mt), bottom(pb), left(pl), right(pr), px(sets for left and right) and py(sets for top and bottom)
